# cnation ZIP 나누기 · 표준 분할 ZIP 버전

아이폰 Safari용 파일·폴더 압축 및 분할 웹앱입니다. 파일은 서버로 전송되지 않습니다.

## 사용 방법

1. 파일 또는 폴더를 선택합니다. 기존 ZIP 파일도 선택할 수 있습니다.
2. 저장할 이름과 분할 용량(MB) 또는 개수를 입력합니다.
3. 생성된 파일들을 아이폰의 같은 폴더에 저장합니다.
4. 분할 ZIP 지원 압축 앱에서 마지막 `파일명.zip`을 열면 전체 내용을 풀 수 있습니다.

생성 형식: `파일명.z01`, `파일명.z02`, … 마지막 `파일명.zip`.
하나만 생성하면 일반 `파일명.zip`으로 저장합니다. 확장자를 바꾸지 마세요.
기존 ZIP은 원본 그대로 새 압축 파일 안에 포함됩니다.
아이폰 기본 파일 앱이 분할 ZIP을 열지 못하면 앱의 ‘다시 합치기’로 일반 ZIP으로 변환하세요.

## GitHub 업로드 및 실행

다운로드한 소스 ZIP은 `index.html`이 최상위에 오도록 구성됩니다.
압축을 풀고 안에 있는 파일과 tests 폴더를 GitHub 저장소 최상위에 올리세요.
GitHub Pages 또는 Vercel 등 HTTPS 정적 호스팅에서 게시하면 됩니다.
패키지 설치, 빌드 명령, API 키, Firebase 설정이 필요 없습니다.
GitHub에 소스만 올리면 앱이 실행되지는 않으므로 Pages 또는 다른 웹 호스팅을 연결해야 합니다.
아이폰 파일 앱에서 index.html을 직접 여는 방식은 지원하지 않습니다.

## 소스 구성

- index.html: 화면
- style.css: 모바일·컴퓨터 디자인
- app.mjs: 파일 선택, 설정, 저장
- worker.mjs: 백그라운드 압축 작업
- zip-core.mjs: 일반 ZIP 생성 및 이전 버전 묶음 복원
- standard-zip.mjs: 표준 분할 ZIP 생성, 검증, 일반 ZIP으로 합치기
- manifest.json, icon-192.png, icon-512.png, apple-touch-icon.png: 홈 화면 추가 관련 정보
- tests/: 압축·분할·복원 검사 코드

원본 개발 저장소에서는 화면 소스가 dist/ 안에 있으며, 다운로드 ZIP에는 최상위에 배치됩니다.

## 범위와 제한

- 한 번에 원본 합계 512 MB, 최대 10,000파일, 분할 최대 200개.
- 용량 입력: 0.07~512 MB, 1 MB = 1,000,000바이트. 지정한 최대 용량 안에 ZIP 정보도 포함됩니다.
- 개수 입력: 1~200. 표준 ZIP의 조각 기준 최소 64 KB와 헤더 경계 때문에 압축 후 크기가 작으면 요청한 개수로 분할할 수 없습니다. 이 경우 개수를 줄이도록 안내합니다.
- ZIP 헤더는 조각 경계에서 잘리지 않으며, 중앙 디렉터리에 디스크 번호와 상대 위치를 기록합니다.
- 조각 크기는 64 KB의 정확한 배수를 피합니다. Info-ZIP zip 3.0이 그 크기의 분할 ZIP을 잘못 합치기 때문입니다.
- 폴더 선택은 iOS 18.4 이상. 빈 폴더는 파일 선택 API의 특성상 포함되지 않습니다.
- 브라우저가 지원하면 DEFLATE로 압축합니다. 미지원 브라우저는 STORE 방식으로 ZIP에 묶습니다.
- 저장 메뉴 지원 여부는 브라우저에 따라 다릅니다. ‘다운로드’로 개별 저장할 수도 있습니다.
- 작업 중 페이지를 열어 두세요. 저장 전 새로고침하면 결과가 사라집니다.
- 실제 처리 가능한 크기는 아이폰 메모리에 따라 달라질 수 있습니다.
- 앱 내 합치기는 이 앱에서 만든 ZIP32/STORE/DEFLATE 분할 ZIP을 대상으로 합니다. 암호화 ZIP, ZIP64, ZIP 주석, 다른 압축 방식은 지원하지 않습니다. 외부 분할 ZIP 전체의 호환성을 보장하지 않습니다.
- 이전 버전의 _01.zip 묶음도 앱 내에서 복원할 수 있습니다.

## 검증

Node.js 24 환경에서 압축, 용량 상한, 정확한 분할 개수, 한글 및 하위 폴더, 손상·누락·중복 검사, 복원 후 원본 바이트 일치를 확인했습니다.
별도 Info-ZIP 프로그램으로 표준 분할 ZIP을 합친 뒤 Python zipfile로 모든 CRC와 원본 내용을 확인했습니다.
중앙 디렉터리가 여러 조각에 걸치는 사례도 확인했습니다.
아이폰 실기기의 파일 선택·공유 메뉴와 모든 압축 앱을 직접 검증한 것은 아닙니다.

검사 실행: `node tests/standard-roundtrip.mjs` (Node.js 24 권장).
